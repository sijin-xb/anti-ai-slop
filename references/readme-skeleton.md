# README.md 骨架

默认结构，按需删节，不要为了「齐全」全上：

1. 项目名 + 一句话说明（做什么、给谁用）
2. 徽章：只在有 CI 或包发布时加，最多一行
3. 快速开始：安装命令 + 最小可运行示例，复制即用
4. 配置：表格或键值列表，只列非默认项
5. 用法：覆盖 80% 场景，长尾内容指向 docs
6. 限制与已知问题
7. 许可证、贡献：各一行

## 各节取舍

- 「功能特性」列表：除非每项都是别人没有的具体能力，否则删。
- 目录：正文 120 行以内不要。
- 截图：不是 GUI 就不要。
- 背景动机：最多一句。
- 路线图、致谢、star 历史、FAQ：默认不加。
- 示例参数用真实值；占位符只允许 API key 这类必须替换的东西，不要 `your-value-here` 满篇。

## 超长时先删什么

特性罗列 → 截图 → FAQ → 大段解释。安装和最小示例永远最后删。

## 写前自检

读者是谁？他打开 README 想复制哪条命令？那条命令在第几行？超过 30 行就是失败。
