# syncdocs 使用说明

syncdocs 在两个目录之间同步 Markdown 文件，按修改时间判断哪些文件需要复制。

## 安装

把 `syncdocs.py` 放进 PATH 即可，无第三方依赖。

## 用法

```bash
syncdocs ./docs-en ./docs-zh --interval 60
```

`--interval` 控制轮询间隔，默认 10 秒，最小 5 秒。

`--retries` 控制单个文件失败后的重试次数，默认 3 次。

`--dry-run` 只列出将要同步的文件，不做任何修改。

`--prune` 删除目标端在源端已不存在的文件。

## 退出码

- 0：同步成功
- 1：部分文件同步失败
- 2：源目录或目标目录不存在

## 注意

目标目录必须预先存在，工具不会自动创建。
