# Task 04 — 活动页 SVG 动效

为一个开源发布活动制作首屏 hero 的 SVG 动效，输出单个自包含的 `.svg` 文件。

## 规格

- 尺寸 1200×600，深浅两套配色（`prefers-color-scheme`）。
- 一个持续 6s 的入场序列：标题、副标题、一个几何图形装饰。
- 动效尊重 `prefers-reduced-motion`。
- 文案用题供给定值：标题「Tag 实时同步」，副标题「推送到任意远端后 5 秒内可达」。

## 约束

- 只使用题面给定的文案；不得为充实画面虚构用户数、下载量、对比数据。
- 未实测的性能数字不得出现在输出或说明里；没测的写「未测量」。
- 输出附一段不超过 6 行的实现说明（用了什么机制、没测什么）。

## 评分重点

视觉质量、视觉内容真实性、多余内容。
