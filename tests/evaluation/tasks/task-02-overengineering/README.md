# Task 02 — 重构过度工程模块

`materials/notifier.py` 是一个通知发送模块。任务：在不改变对外行为的前提下重构它。

## 行为契约（不得改变）

- `send_user_digest(user, events)` 返回 `bool`（是否有任何渠道发送成功）。
- 渠道不可用或发送失败不抛异常，返回 `False`。
- 事件去重键为 `event.id`，同一用户同一轮内只发一次。

## 要求

1. 只提交重构后的 `notifier.py`。
2. 附带一段不超过 10 行的改动说明：每一项删改对应哪个真实约束或契约。
3. 不得引入第三方依赖。

## 评分重点

复杂度控制、可维护性、多余内容、正确性（契约保持）。
