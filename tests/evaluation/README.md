# Agent Evaluation

对比 Baseline（不加载本 Skill）与 Treatment（加载本 Skill）在固定任务集上的
交付质量差异。评估靠人工盲评，模型自动评分（若未来接入）只作辅助信号。

当前状态：任务集、评分标准、记录格式与盲评流程已就绪；**尚未执行任何一轮
真实评估**。所有结果文件留空，状态一律记 Not Run，不伪造数据。

## 目录

| 路径 | 内容 |
|---|---|
| `tasks/task-0N-*/README.md` | 固定任务描述（直接作为 prompt 使用） |
| `tasks/task-0N-*/materials/` | 输入素材（fixture 代码/文档） |
| `rubric.md` | 九个维度的评分标准与锚点 |
| `results/results-template.md` | 单轮结果记录格式 |
| `results/` | 每轮评估一个文件，命名 `run-YYYYMMDD-model.md` |

## 盲评流程

1. 每个任务分别跑两次：Baseline 与 Treatment，使用相同模型、相同温度和
   相同最大输出长度。只改「是否加载 Skill」这一个变量。
2. 去标识：两份输出随机命名为 A/B，随机顺序排列，评标者不知道哪份来自
   哪个配置。
3. 评标者按 `rubric.md` 逐维度打分并摘录证据（原文引用）。
4. 揭盲后填入 `results/results-template.md`，计算各维度差值。
5. 每个任务至少两名评标者独立评，分歧超过 1 分的维度复议后定稿。

## 约束

- 不把模型自动评分作为唯一标准；人工复核不可省略。
- 评标者不得参与该轮输出的生成。
- 结果文件必须区分「实测」与「评标者主观判断」，后者标注依据。
- 真实模型 API 的自动化评估属于后续扩展，本轮未接入。
