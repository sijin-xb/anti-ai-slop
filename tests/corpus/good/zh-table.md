# 错误码

| 码 | 含义 | 处理 |
|---|---|---|
| `E001` | 配置文件缺失 | 用 `--config` 指定路径，或确认工作目录 |
| `E002` | 配置文件语法错误 | 按输出行号修正 TOML |
| `E003` | 必填字段为空 | 补齐字段后重试 |
| `E010` | 端口被占用 | 用 `ss -ltnp` 找到进程并停止 |
| `E011` | 权限不足 | 检查配置文件与日志目录属主 |
| `E020` | 迁移未完成 | 等待，或查看迁移日志 |
| `E021` | 迁移版本回退 | 拒绝启动；不得直接降级数据库 |

`E001` 与 `E002` 都可能在启动早期出现，日志此时只有 stderr 输出，journal 中看不到。直接在前台运行二进制可看到完整信息。
