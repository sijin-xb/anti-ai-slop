# 커넥션 풀

풀은 연결을 필요할 때 엽니다. 유휴 연결이 없으면 호출자는 기다리거나, `max_size` 범위 안에서 새 연결을 만듭니다.

풀이 가득 차면 `acquire_timeout`이 대기 시간을 정합니다. 기본값은 5초입니다. 0으로 설정하면 경합한 요청은 즉시 실패합니다.

유휴 연결은 `idle_timeout`이 지나면 닫힙니다. 정리 작업은 1분마다 실행되므로 실제로는 최대 60초 더 남을 수 있습니다.

2.1.0 버전에서 `max_size` 기본값을 10에서 25로 바꾸었습니다. 이전 기본값에 의존하는 환경에서는 값을 직접 지정하십시오.

```toml
[pool]
max_size = 10
acquire_timeout = 5
```
