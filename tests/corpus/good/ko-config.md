# 설정 불러오기

프로그램은 `config.toml`에서 설정을 읽습니다. 필수 항목이 없으면 종료 코드 2로 멈춥니다.

## 읽는 순서

1. 명령줄 `--config`로 지정한 경로.
2. 환경 변수 `APP_CONFIG`.
3. 현재 디렉터리의 `config.toml`.

앞 단계에서 파일을 찾지 못한 경우에만 다음 단계를 사용합니다. 여러 파일을 합치지는 않습니다.

## 실패 처리

| 상황 | 동작 |
|---|---|
| 파일이 없음 | 내장 기본값으로 시작 |
| 문법 오류 | 시작을 거부하고 줄 번호 출력 |
| 값이 범위를 벗어남 | 시작을 거부하고 항목명과 허용 범위 출력 |

줄 번호는 1부터 세며 주석 줄도 포함합니다.
