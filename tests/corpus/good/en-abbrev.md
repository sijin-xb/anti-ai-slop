# Migration Notes

Dr. Chen reviewed the v2.1.0 upgrade path. The e.g. sample in section 3 still
applies, i.e. no schema change is required.

The client supports v2.1.0 and v2.0.5. Version 1.9.8 is no longer accepted.
Upgrade in one step from 1.9.8 to 2.1.0 only after running the baseline suite;
the 2.0.x series is not an intermediate requirement.

Releases are tagged U.S. Pacific time. The cutoff is 18:00 p.m. local, or
approximately 02:00 UTC the next day.
