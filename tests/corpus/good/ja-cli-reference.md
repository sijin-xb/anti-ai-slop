# コマンドリファレンス

## sync

```bash
relay sync --from ./inbox --to ./archive --dry-run
```

`--dry-run` を付けると移動対象の一覧だけを出力し、ファイルは変更しない。
終了コードは 0 が成功、1 が検証エラー、2 が設定読み込みエラー。

## prune

保持期間を過ぎたアーカイブを削除する。`--keep 30` を指定すると直近 30 世代を残す。
削除前にサイズを出力するので、ログから解放容量を確認できる。

| オプション | 既定値 | 説明 |
|---|---|---|
| `--keep` | `10` | 残す世代数 |
| `--force` | なし | 確認を省略する |

## 設定ファイル

設定は TOML で記述する。`timeout_secs` の既定値は 30 で、0 を設定するとタイムアウトなしになる。
ネットワーク越しの転送では 60 以上を推奨する。根拠は添付の測定結果を参照。
